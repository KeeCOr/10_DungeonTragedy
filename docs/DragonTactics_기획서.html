문제 정의

짧은 시간에 전략 퍼즐을 즐기고 싶은 PC 인디 전략 플레이어는, 보스 패턴의 예고와 행동 결과가 충분히 명확하지 않으면 선택의 의미를 느끼기 어렵다. DragonTactics는 드래곤의 다음 공격을 읽고 카드 1장으로 피해를 줄이거나 보상을 노리는 3x5 보드 전술 게임이다.

주 페르소나

  • 한승민, 35세, 기획팀 과장
  • Into the Breach식 격자 전술과 짧은 PC 인디 전략 게임 선호
  • 퇴근 후 10~20분 동안 한 판을 집중해서 플레이
  • 예상 피해와 실제 결과가 바로 보여야 다음 판단을 납득한다

핵심 루프

  1. 드래곤 공개 카드와 위협 셀 확인
  2. 손패에서 행동 1개 선택
  3. 보드 위치와 미션 조건에 맞게 실행
  4. 드래곤 턴 피해와 결과 요약 확인
  5. 다음 공격 프리뷰를 보고 새 판단으로 복귀
