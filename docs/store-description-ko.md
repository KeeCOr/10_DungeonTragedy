# Dragon Tactics — 한국어 스토어 설명

## 짧은 설명 (80자 이내)
용사 파티를 이끌고 드래곤 보스에 맞서라. 카드를 뽑고, 전술적으로 배치하고, 숨겨진 임무를 완수하라.

---

## 긴 설명

**드래곤을 넘어서라. 토너먼트에서 살아남아라.**

Dragon Tactics는 최대 4인의 영웅 파티가 3×5 격자 위에서 드래곤 보스와 맞서는 턴제 카드 보드게임입니다. 적의 모든 움직임은 미리 공개됩니다. 포지셔닝과 타이밍이 전부입니다.

**핵심 게임플레이**
매 라운드 주사위로 행동 순서를 정합니다. 자기 차례에 패에서 카드 한 장을 선택하세요 — 이동, 공격, 치유, 정찰, 도발 — 또는 패를 전부 버리고 비밀 임무를 재배정하세요. 드래곤의 다음 공격은 미리 공개됩니다. 위치와 타이밍이 생사를 가릅니다.

**주요 특징**
- **4개 종족** — 인간, 엘프, 드워프, 오크, 각자 고유 패시브
- **40장 공유 덱** — 이동, 공격, 은신, 치유, 정찰, 희귀 보물 카드
- **숨겨진 임무** — 필수 1개 + 선택 1개. 협력 또는 대립 미션이 긴장감을 만든다
- **예고형 드래곤 AI** — 다음 행동을 미리 알 수 있다. 피할지 맞설지 선택하라
- **3전 토너먼트** — 3판의 누적 점수로 최종 승자를 가린다
- **AI 동료** — 규칙 기반 AI가 나머지 파티원을 조종

**개발 철학**
Dragon Tactics는 짧고 전략적인 경험을 추구합니다. 한 판에 10~20분. 계정 불필요, 인터넷 연결 불필요, 허수 없이 — 오직 전술뿐입니다.
