## 심사 진행 경로

### Steam
Steamworks 파트너 대시보드 → 스토어 페이지 → 기본 정보 → "IARC 등급 설문" 클릭 → 위 표대로 응답

### Google Play
Play Console → 앱 콘텐츠 → 연령 등급 → 설문지 시작 → 카테고리: 게임 → 응답 후 저장

### App Store
App Store Connect → 앱 정보 → 연령 등급 → 각 카테고리 "없음" 또는 "경미" 선택
