# DragonTactics 기획서 v0.4.0

최종 갱신: 2026-07-16 KST
플랫폼: 웹 브라우저, 순수 HTML/CSS/JavaScript + Node 정적 서버
검증 명령: `npm test`

## 문제 정의
짧은 시간에 전략 퍼즐을 즐기고 싶은 PC 인디 전략 플레이어는, 기존 카드 전술 게임에서 보스 패턴의 예고와 행동 결과가 충분히 명확하지 않으면 “내 선택이 의미 있었다”는 감각을 얻기 어렵다. DragonTactics는 드래곤의 다음 공격을 읽고, 아군 위치와 카드 1장을 선택해 피해를 줄이거나 보상을 노리는 3x5 보드 전술 게임이다.

## 주 페르소나
- 이름: 한승민
- 나이: 35세
- 직업: 기획팀 과장
- 선호 장르: Into the Breach식 격자 전술, 짧은 PC 인디 전략 게임
- 사용 맥락: 퇴근 후 10~20분 동안 한 판을 집중해서 플레이한다.
- 기대: 드래곤 공격 예고, 예상 피해, 실제 결과가 한눈에 보여야 다음 판단을 납득할 수 있다.

## 핵심 루프
1. 플레이어가 드래곤의 공개된 공격 카드와 위협 셀을 확인한다.
2. 손패에서 이동, 공격, 숨기, 치유, 정찰, 도발, 보물 중 1장을 선택한다.
3. 보드 위치와 미션 조건을 고려해 행동을 실행한다.
4. 드래곤 턴에서 공개 카드가 해결되고 HP, 피해, 탈락 여부가 갱신된다.
5. 결과 요약과 다음 공격 프리뷰를 보고 다음 턴 판단으로 돌아간다.

## v0.4.0 핵심 개선
- 드래곤 활성화 전에 예상 총 피해, 피격 대상, shield/hide 완화 여부를 `Preview` 패널로 표시한다.
- 드래곤 턴 해결 후 실제 피해, 피해 대상, 탈락 여부를 `Last result` 패널로 표시한다.
- `getDragonActivationPreview(state)`가 사전 피해 예측을 계산한다.
- `executeDragonTurn()`이 `dragon.lastActivationSummary`를 저장한다.
- 조기 사용, 지연 사용, 기회 상실을 다루는 드래곤 타이밍 튜토리얼 시나리오 3개를 데이터와 테스트로 추가했다.
- 위협 셀은 `public/assets/threat-marker-decal-atlas.png` 3슬롯 데칼 아틀라스를 사용해 보드 위협도를 더 강하게 보여준다.

## UI/HUD 규칙
- 위협 셀 데칼은 토큰, HP, 보상, 피해 숫자보다 낮은 레이어에 둔다.
- 드래곤 패널은 `Preview`, 공개 카드, `Last result` 순서로 읽히게 한다.
- 플레이어의 주요 턴 선택은 카드 사용 또는 드로우 계열 행동 1개로 제한한다.
- 버튼과 셀은 44px 이상 클릭 영역을 유지한다.
- 긴 텍스트는 패널 내부에서 줄바꿈하고, 보드 위 핵심 숫자는 가리지 않는다.

## 남은 리스크와 다음 우선순위
1. 상업 출시를 추진하려면 Electron 포터블 또는 Vite 기반 브라우저 빌드 구성이 필요하다.
2. Into the Breach와의 차별점은 “드래곤 활성화 타이밍 읽기”와 “미션 기반 점수 경쟁”으로 더 선명하게 밀어야 한다.
3. 남은 SVG/코드 드로잉 리소스는 실제 런타임 참조를 확인한 뒤 PNG/아틀라스로 교체한다.
4. 결과 화면에서 “왜 이 피해가 났는지”를 더 짧은 문장으로 리플레이하는 기능이 다음 고가치 개선이다.
